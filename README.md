# Play and Learn

A browser-based learning game for children with cerebral palsy. Works offline, installs like an app, and supports touch, hand pointer, head pointer, or a single switch as input so a child can play without needing fine motor control.

Three games: **Bubble Pop** (steady pointing), **Pick & Learn** (numbers, colours, animals), **Finger Quest** (show fingers to the camera).

Everything is saved on the device only  no server, no account, camera pictures never stored.
